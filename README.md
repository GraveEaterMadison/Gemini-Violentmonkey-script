# Rovetify : YouTube Summary with Gemini 🚀


**Rovetify** is a clean and powerful YouTube video assistant. It leverages Google Gemini AI to provide structured summaries, real-time video chat, bilingual synced subtitles, and transcript export—all while seamlessly integrating into the native YouTube UI.

**Rovetify** 是一款纯净且强大的 YouTube 视频助手。它利用 Google Gemini AI 提供结构化总结、实时视频对话、双语同步字幕以及文本导出功能，并完美融入 YouTube 原生 UI。

---

## ✨ Key Features / 核心功能

*   **🤖 AI Deep Summary / AI 深度总结**  
    Based on the latest Gemini models, extract core video insights with a single click.  
    基于 Gemini 最新模型，一键精准提取视频核心要点。

*   **💬 Video AI Assistant / 视频互动助手**  
    Ask AI questions about video content in real-time, just like having a personal tutor.  
    针对视频内容实时向 AI 提问，像有了一个贴身视频助教。

*   **🌐 Bilingual Subtitles / 双语同步字幕**  
    Intercept native subtitle streams for smooth bilingual comparison and easy export.  
    底层拦截原生字幕流，实现丝滑的双语对照并支持一键导出。

*   **🎨 Native UI Design / 原生级 UI 设计**  
    100% compatible with YouTube's Dark/Light modes for a superior visual experience.  
    100% 适配 YouTube 深浅色模式，保持视觉体验的高度一致性。
