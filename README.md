# Rovetify : YouTube Summary with Gemini 🚀

**Rovetify** 是一款纯净且强大的 YouTube 视频助手。它利用 Google Gemini AI 提供结构化总结、实时视频对话、双语同步字幕以及文本导出功能，并完美融入 YouTube 原生 UI。

---

## ✨ Key Features / 核心功能

*   **🤖 AI 深度总结**：基于 Gemini 1.5/2.0 模型，一键精准提取视频要点。
*   **💬 视频互动助手**：针对视频内容实时向 AI 提问，像有了一个贴身助教。
*   **🌐 双语同步字幕**：底层拦截原生字幕流，实现丝滑的双语对照并支持导出。
*   **🎨 原生级 UI 设计**：100% 适配 YouTube 深浅色模式，视觉体验极佳。

---

## 🚀 Installation / 安装

1.  首先安装脚本管理器 [Tampermonkey](https://www.tampermonkey.net/)。
